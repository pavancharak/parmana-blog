This is part 7 of the series Product in practice. Part 6 covered calling the API directly. This part covers the SDKs that wrap those calls.

There are quickstarts for the TypeScript and Python SDKs. Each one takes you from installation to a first request.

Use the SDK when you want the calls wrapped for you, and the direct API when you need to see every request.

## What it does not do

The quickstarts cover the first request. They do not cover production configuration, which is in the deployment guides.
